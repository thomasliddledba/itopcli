# Changelog

## 0.1.0

Initial packaged release, prepared for publication.

- Query, create, update, and delete iTop objects with JSON output.
- Preview REST payloads with `--dry-run`.
- Configure connection settings, timeouts, TLS verification, and a default organization.
- Accept field values through repeated `--set` options or `--fields-json`.
- Escape apostrophes and backslashes in query values.
- Preserve literal percent characters in configuration credentials.
- Install the `itopcli` command with pip on Python 3.10 or newer.
- Include offline regression tests and automated release validation.
